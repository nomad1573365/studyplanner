# 📚 StudyPlannner v0.7-Alpha

時間のかかるタスクを期日までに終わらすことに特化した学習支援DiscordBot(開発中)  
簡単に言うと、参考書を終わらせるという大きな目標を、週、日と身近なものにするものです

## 主な機能
- **目標管理**: `/make_goal` で参考書の総ページ数と期限を設定。
- **重み付け**: `/weight` で今週重点的に片付けるタスクを設定。(`/reset_weight`でリセットできます。)
- **進捗記録**: `/rc` で今日の勉強を記録。
- **進捗閲覧**: `/goals` や `/td` で進捗を閲覧。

## 使い方
- 終わらせたいタスクと期日を入力(`/make_goal`)
- 今日やるべき量が自動で提案されます
- それに従って日々こなせば期日までに完了します(`/td`で閲覧)

## 技術スタック
- Language: Python 3.14
- Library: discord.py
- Database: PostgreSQL (外部)
