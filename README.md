# 📚 StudyPlannner v0.9-Alpha

時間のかかるタスクを期日までに終わらすことに特化した学習支援DiscordBot(開発中)  
簡単に言うと、参考書を終わらせるという大きな目標を、週、日と身近なものにするものです

## 主な機能
- **簡単に記録**: v0.8-Alphaより追加したダッシュボードで簡単に進捗を記録。(`/dashboard_refresh`でリセット。)
- **目標を管理**: `/make_goal` で参考書の総ページ数と期限を設定。(`/edit_goal`で編集できます。)
- **重み付け**: `/weight` で今週重点的に片付けるタスクを設定。(`/reset_weight`でリセットできます。)
- **進捗記録**: `/rc` で今日の勉強を記録。
- **進捗を閲覧**: `/goals` や `/td` で進捗を閲覧。(どこで実行しても、自分にしか見えません。)
- **進捗を共有**: `/td_pub`や`/goals_pub`をサーバーなどで実行すると、周りに公開できます。

## 使い方
- 終わらせたいタスクと期日を入力(`/make_goal`)
- 今日やるべき量が自動で提案されます
- それに従って日々こなせば期日までに完了します(`/td`やダッシュボードで閲覧)

## 技術スタック
- Language: Python 3.14
- Library: discord.py
- Database: PostgreSQL (外部)
