# 📚 StudyPlannner v0.2-Alpha

時間のかかるタスクを期日までに終わらすことに特化した学習支援DiscordBot(開発中)
簡単に言うと、参考書を終わらせるという大きな目標を、週、日と身近なものにするものです

## 主な機能
- **目標管理**: `/make_goal` で参考書の総ページ数と期限を設定。
- **戦略提案**: `/weekly_sg` で残り日数から今週の理想的なペースを算出。
- **簡単設定**: `/sync` で理想的なペースに基づいてタスクを自動設定。
- **重み付け**: `/weight` で今週重点的に片付けるタスクを設定。
- **進捗記録**: `/record` で今日の勉強を記録。
- **進捗閲覧**: `/goals` や `/today` で進捗を閲覧。

## 使い方
- 終わらせたいタスクと期日を入力(`/make_goal`)
- そのタスクを今日のやることリストに登録(`/sync`や`/add_todo`)
- あとは指示に従って日々こなすだけ(`/today`で閲覧)
