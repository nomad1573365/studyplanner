# 📚 StudyPlannner v1.0-Beta

時間のかかるタスクを期日までに終わらすことに特化した学習支援DiscordBot(開発中)  
簡単に言うと、参考書を終わらせるという大きな目標を、週、日と身近なものにするものです

## 主な機能
- **簡単に記録**: DMに生成されるダッシュボードで簡単に進捗を記録。
- **目標を管理**: `/make_goal` で参考書の総ページ数と期限を設定。
- **重み付け**: `/weight` で今週重点的に片付けるタスクを設定。
- **進捗記録**: `/rc` で今日の勉強を記録。
- **進捗を閲覧**: `/goals` や `/td` で進捗を閲覧。(どこで実行しても、自分にしか見えません。)

## 使い方
- 終わらせたいタスクと期日を入力(`/make_goal`)
- 今日やるべき量が自動で提案されます
- それに従って日々こなせば期日までに完了します(`/td`やダッシュボードで閲覧)

## コマンド一覧
### 目標の管理
- `/make_goal`: 新しい学習目標（参考書など）を作成します。開始/終了ptsや期限を設定できます。
- `/edit_goal`: 登録済みの目標の内容を修正します。現在の値がデフォルトで入力されますので、変更しないものはそのままにしてください。
- `/delete_goal`: 入力されたゴールと関連する記録を削除します。

### 日々の記録
- `/rc`: 入力された分だけ今日の学習進捗を進めます。(マイナスを入れればその分減らせます。)
- `/weight`: 今週の特定タスクの重み付けを変更します。およそ入力倍します。(必ずしも入力倍になるわけではありません。)
- `/reset_weight`: 今週の重み付けをすべて1に戻します。
- `/rc_forgot`: 過去に記録し忘れた進捗を記録します。(その日にそのゴールがタスクとして登録されている必要があります。)

### 進捗の確認・設定
- `/td`: 今日のタスクを表示します。(非公開)
- `/goas_pub`: 現在進めているゴール一覧を表示します。(非公開)
- `/td_pub`: `/td`を周りに公開したいときにご使用ください。
- `/goals_pub`: `/goals`を周りに公開したいときにご使用ください。


### その他
- `/dashboard_refresh`: ダッシュボードを再生成します。
- `/delete_msg`: 残ってしまったBotからのメッセージを削除する際にご使用ください。
- `/about`: このBotの情報を表示します。
- `/barusu`: 自分のデータをすべて初期化（消去）します。

## ご留意ください
- このBotは、ページ数や問題数などを区別せず"pts"として扱います。なにを1ptsとするか覚えておいてください。
- バグが発生した際は、trace_idとともに報告してくださると助かります。
